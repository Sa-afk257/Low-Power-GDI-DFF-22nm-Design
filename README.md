# Low-Power GDI D Flip-Flop with Adaptive Clocking

## Project Overview

This project presents the design and simulation of a low-power 12-transistor Gate Diffusion Input (GDI) D Flip-Flop integrated with a CMOS adaptive clocking system targeting 22nm SoC applications.

The work combines both theoretical research and practical circuit implementation, including schematic design, simulation, timing analysis, power evaluation, and layout generation.

## Implemented Blocks

- GDI Transmission Gate
- GDI Inverter
- 12-Transistor GDI D Flip-Flop
- XOR Phase Detector
- Ring Voltage Controlled Oscillator (VCO)
- Charge Pump
- Adaptive PLL-Based Clocking System

## Design Tools

- LTspice / Circuit Simulator
- CMOS 22nm Technology Models
- Layout Design Tools
- Timing and Power Analysis Tools

## Results

- Technology Node: 22nm
- Transistor Count: 12
- Dynamic Power: 1.16 µW
- Area: 4444 nm²
- Average Clock-to-Q Delay: 0.9 ns

## Research Contributions

- Reduced transistor count by 40% compared to conventional CMOS designs.
- Lower power consumption and smaller silicon area.
- Integration of adaptive CMOS clocking for improved timing reliability.
- Suitable for low-power IoT and edge-computing SoC applications.
